# Summer_to_Winter_Domain_Cycle_GAN
In this project, summer to winter domain transformation was performed using Cycle GAN (Generative Adversial Network)
on Summer2Winter Yosemite dataset.(Source:Kaggle)

# Dataset Description
Summer2Winter Yosemite dataset ("https://www.kaggle.com/datasets/balraj98/summer2winter-yosemite") consists of 1540 Summer Photos & 1200 Winter Photos with each split into train and 
test subsets. \
